Rigby High School Website Project

A responsive school website built for Rigby High School using custom CSS and HTML, styled around the Trojan maroon and gold color scheme.

How to run:
Just follow this link!
https://ridgeturner.github.io/Rigby-High-School/

What's Included
- Home (index.html): Main landing page with school announcements and quick links.
- Academics (academics.html): Course overview, academic pathways, and department info.
- Athletics (athletics.html): Trojan sports schedules, team rosters, and links to RankOne, MaxPreps, NFHS Network, and Hudl.
- Clubs (clubs.html): Full list of student clubs (VEX Robotics, BPA, FFA, SkillsUSA, STUCO, NHS, Drama, Esports, etc.) organized into collapsible dropdowns by category.
- Faculty (faculty.html): Staff directory broken down by department using responsive CSS grids and direct email links.
